# Magnificat edition project

This is a clean project folder for the longer Browne Magnificat example.

## Structure

- `index.html` — main page
- `css/styles.css` — styling
- `js/links.js` — mapping data and main MEI path
- `js/app.js` — rendering and overlay logic
- `mei/browne-main.mei` — main Browne excerpt
- `mei/horwood-bars-34-35.mei` — linked comparison excerpt

## What to do next

1. Replace `mei/browne-main.mei` with your longer Browne excerpt.
2. Replace `mei/horwood-bars-34-35.mei` with your real Horwood excerpt.
3. Open the `magnificat-edition` folder in VS Code.
4. Run `index.html` with Live Server.
