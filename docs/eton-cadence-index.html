Eton Cadence Index

This database allows you to filter, sort, and click a cadence to view its notated exemplar where available. It does not contain all pieces in the Eton Choirbook, but instead a limtied selection. This database should be taken as an indicative exemplar of what would be possible if more of the corpus was digitally encoded. It should also be noted that some of the musical examples feature a lot of blank white space. This is due to an issue with how the png files were collated. As such, this Candence index is best viewed on PCs and devices with larger screens.
